# UI Redesign Brief — SIMPUS Mini

Saya ingin melakukan **REDESIGN UI ONLY** pada project:

`https://github.com/Farhan-L4h/Praktikum_Pweb/tree/main/jobsheet-13`

Project ini adalah **SIMPUS-Mini (Sistem Informasi Perpustakaan Mini)** berbasis:

- PHP Native
- PostgreSQL
- PDO_PGSQL
- HTML5
- CSS3
- JavaScript

## TUJUAN UTAMA

Buat seluruh antarmuka aplikasi menjadi lebih modern, unik, eye-catching, dan profesional dengan gaya:

> **Neo-Brutalism + Dark Mode Only**

UI harus terasa seperti aplikasi dashboard modern, tetapi tetap mempertahankan karakter Neo-Brutalism yang kuat.

Fokus utama adalah:
- visual hierarchy
- typography
- spacing
- layout
- cards
- buttons
- forms
- tables
- navigation
- dashboard
- responsive design
- hover/focus states
- empty/error/success states

# DESIGN SYSTEM

## 1. Theme

Gunakan **DARK MODE ONLY**.

Tidak perlu:
- light mode
- theme switcher
- auto theme
- system theme detection

Aplikasi harus selalu tampil dark.

### Recommended palette

Gunakan warna dasar gelap:

```css
--bg: #0b0b0b;
--surface: #151515;
--surface-2: #1d1d1d;
--text: #f5f5f5;
--muted: #a3a3a3;
--border: #f5f5f5;
